# Isa Gutierrez portfolio

This is a static portfolio for GitHub Pages. The website is `index.html`, `styles.css`, and `script.js`; `resume.pdf` is the downloadable résumé. There is no build step. GitHub Pages can publish directly from the root of the `main` branch.

To add photography, place image files in an `images/` folder and replace the `.photo-slot` placeholder content in `index.html` with `<img src="images/filename.jpg" alt="Description">`. To use custom fonts, add licensed `.woff2` files to a `fonts/` folder, define them with `@font-face` in `styles.css`, and update `--font-display` and `--font-body`.

The page copy was prepared from Isa's September 2026 résumé, November 2024 master résumé, and public Showspace portfolio. The music section intentionally waits for Isa's selections.
